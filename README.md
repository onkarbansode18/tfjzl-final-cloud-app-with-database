# Emotion Detector

## Project Description

This project is an AI-based Emotion Detector application developed
using IBM Watson NLP and Flask.

The application detects emotions such as:
- Anger
- Disgust
- Fear
- Joy
- Sadness

## Technologies Used

- Python
- IBM Watson NLP
- Flask
- HTML
- JavaScript
